# Azelle website audit — issues found

Date: 11 October 2026. Target: local storefront at http://localhost:5173/ and source in D:/Azelle_Web.

This is an audit, not an implementation change. P1 = resolve before launch; P2 = important improvement; P3 = refinement. Source findings are distinguished from browser observations and performance risks. This is not a guarantee that every possible defect has been found.

The unlabelled-link counter in these raw measurements includes intentionally aria-hidden product image links; those are not counted as accessibility defects here. The small-control counter also includes hidden radio inputs; their visible labels are the relevant targets.

Additional checks: Contact Us, Shipping Policy and Get Help at 390 and 768 px had no observed horizontal overflow; [measurements](D:/Azelle_Web/artifacts/site-audit/support-page-checks.json). [Cart evidence](D:/Azelle_Web/artifacts/site-audit/mobile-cart.png). No order was placed.

The current production build passes TypeScript and Vite compilation (130 modules). The main JS chunk is approximately 104 kB gzip and main CSS 26 kB gzip. No browser warning/error entries were captured during the initial core-page matrix. These are not Lighthouse or Core Web Vitals scores.

Public product routes had already been verified for their distinct product descriptions, bottle images, prices and controls in the preceding implementation check. This audit sampled Imperium across every breakpoint. Private admin screens, authenticated account/order screens, real payment/refund/shipping transactions, real devices and production crawl/indexing were not exercised. Hover styles were inspected in source; not every hover was exercised with a pointer. Slow-network and reduced-motion device emulation remain pending.

## SEO / AEO / GEO / LLMO interpretation

AEO means making answers easy to retrieve; GEO and LLMO here refer to usefulness and visibility in AI/LLM-mediated search. These are not independent pass/fail certifications. For this site, the central gaps are crawlable content, accurate consistent facts, entity credibility and page-specific metadata—not keyword stuffing or an invented AI score.

Google states that ordinary SEO fundamentals remain relevant to AI features and that no special AI text file or special schema is required. Product structured data is a separate supported search enhancement. Sources: [Google AI features guidance](https://developers.google.com/search/docs/appearance/ai-features), [Google product structured data](https://developers.google.com/search/docs/appearance/structured-data/product). These sources inform recommendations; local defects above come from browser/source evidence.
